# CNN-use-of-BEATRIX-MATLAB
This code runs a low level CNN for face detection and another for emotion detection, moving towards a face with a custom emotion
This code made use of two built in MATLAB CNNs: 

[1] Justin Pinkney (2026). MTCNN Face Detection (https://github.com/matlab-deep-learning/mtcnn-face-detection/releases/tag/v1.2.4), GitHub. Retrieved March 11, 2026.

[2] Matlab Mebin (2026). Deep Learning ,Deep neural network- CNN Emotion Recognition (https://uk.mathworks.com/matlabcentral/fileexchange/68157-deep-learning-deep-neural-network-cnn-emotion-recognition), MATLAB Central File Exchange. Retrieved March 11, 2026.
